# Sources of Strength Race/Ethnicity Data

Responses to the check-all-that-apply race/ethnicity question at four
time points from a randomized controlled trial of the Sources of
Strength program.

## Usage

``` r
sources_race
```

## Format

A data frame with 16,922 rows and 9 columns:

- ID:

  Subject identification number

- Wave:

  Data collection time point

- Black, Native_American, Asian, Hispanic, Multiracial,
  Pacific_Islander, White:

  Indicator variables for check-all-that-apply responses where 1 =
  endorsement
